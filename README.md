# HS World History: Enlightenment to Present (Mississippi)

Lesson content repo for Optima Academy Online's **HS World History: Enlightenment to Present** course (Mississippi College- and Career-Readiness Standards, World History — Age of Enlightenment to Present, 12 competencies).

This repo is the source of truth for lesson content, hosted via GitHub Pages. Canvas course 228 links/embeds to pages here rather than carrying inline copies of the content.

**Build scope for this repo, current phase:** Fall semester only (Quarter 1 + Quarter 2, weeks 1–18). Spring semester (Quarter 3 + Quarter 4, weeks 19–36) is out of scope until a future build phase.

Course identity, build conventions, and session-to-session context live in `CLAUDE.md` in the course workshop folder (OneDrive: `Course workshops/HSMissWorldHist-Enlightenment/`), not in this repo. Read that file before building anything here.

## Structure

```
hs-world-history-enlightenment-ms/
├── README.md
├── index.html                    ← GitHub Pages landing page (placeholder)
├── quarter-01-reason-rights-revolution/    ← Weeks 1-9
└── quarter-02-industry-and-ideology/       ← Weeks 10-18
```

Week folders (`week-01/`, `week-02/`, ...) are created as each week is actually built — this repo does not pre-scaffold empty week folders.
